# AWTRIX NG – Media now playing

A Home Assistant blueprint that shows what a media player is playing on an
[AWTRIX NG](https://github.com/Blueforcer/awtrix-ng) clock, every time playback
starts or is paused. It works with any `media_player` entity: Plex, Spotify,
Sonos, Apple TV, Google Cast…

## What it shows

| Media | Text on the clock |
| --- | --- |
| TV episode | `Series S01E02 - Title` |
| Music | `Artist - Title` |
| Movie, video, anything else | `Title` |
| No title (radio, apps…) | Channel, app or player name |

## Requirements

- Home Assistant 2024.10 or newer
- The [MQTT integration](https://www.home-assistant.io/integrations/mqtt/),
  connected to the same broker as your AWTRIX NG
- An AWTRIX NG with MQTT enabled

## Installation

Click the **Import blueprint** button above, or in Home Assistant go to
**Settings → Automations & scenes → Blueprints → Import blueprint** and paste:

```text
https://github.com/AkdM/awtrix-ng-ha-media-blueprint/blob/main/media_awtrix_ng_blueprint.yaml
```

Then choose **Create automation** on the blueprint and fill in the inputs.

## Inputs

| Input | Default | Description |
| --- | --- | --- |
| Media players | – | One or more `media_player` entities to watch |
| AWTRIX NG notify topic | – | `<your MQTT prefix>/cmd/notify`, e.g. `awtrix-ng/cmd/notify` |
| Play icon | embedded | Name of an icon stored on your AWTRIX NG, or empty for the embedded one |
| Pause icon | embedded | Same, for pause |
| Wake up display | on | Turn the matrix on if it is off |
| Repeat | 1 | How many times the text scrolls |

## Updating

Home Assistant does not update blueprints on its own. To get the latest
version, go to **Settings → Automations & scenes → Blueprints**, open the ⋮ menu
of *Media now playing on AWTRIX NG* and choose **Re-import blueprint**. Your
automations keep their settings.

## Customising the icons

The icons are generated by [`icons/make_icons.py`](icons/make_icons.py)
(Python 3, no dependencies). Edit the shapes, colors or timings at the top of
the file, then run:

```sh
python3 icons/make_icons.py
```

It rewrites `icons/play.gif`, `icons/pause.gif`, the previews in
`icons/preview/` and the icons embedded in the blueprint.

## How it works

Each time a watched player changes to `playing` or `paused`, the blueprint
publishes an AWTRIX NG notification to the topic you chose. The icon travels
inside the payload as a base64 GIF: AWTRIX NG reads any `icon` value longer
than 64 characters as inline image data instead of a file name.
